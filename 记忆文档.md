# ESP32S3_PPP_V1 记忆文档

## Project Identity

- Project name: `ESP32S3_PPP_V1`
- Hardware: `ESP32-S3 + EC200A`
- Uplink mode: `PPP`
- Goal: stable 4G to Wi-Fi routing baseline

## Key Facts

- EC200A must use independent `3.8V` power supply
- Power supply peak current should be at least `2A-3A`
- Common ground between ESP32-S3 and EC200A is mandatory
- EC200A USB wiring:
- `DP -> GPIO20 / USB D+`
- `DM -> GPIO19 / USB D-`
- `GND -> GND`
- Debug / flash port is `CH340`
- 4G module uses native USB OTG host port

## Software Baseline

- ESP-IDF: `v6.0.1`
- Project target: `esp32s3`
- SoftAP + WebUI + PPP + NAPT are the baseline capabilities
- `main.c` should remain a startup coordinator only

## Module Responsibilities

- `app_config`: NVS storage, Wi-Fi/APN defaults, validation
- `app_state`: shared runtime snapshot
- `wifi_ap`: SoftAP start, stop, runtime reconfigure, DNS handoff
- `webui`: status view, Wi-Fi/APN config, redial, reboot
- `cellular_ppp`: USB Host CDC-ACM, AT, PPP, NAPT
- `led_status`: field diagnosis through WS2812 phases
- `system_monitor`: temperature + FreeRTOS task distribution

## Stable Experience

- PPP stable path comes from local `S34GV1`
- Prefer separate AT and PPP interfaces when possible
- Debug order:
- `1. board flash/serial ok`
- `2. SoftAP ok`
- `3. WebUI ok`
- `4. EC200A USB enumerate ok`
- `5. AT ok`
- `6. PPP got IP`
- `7. NAPT works for clients`

## Maintenance Habit

- New feature must not be stuffed into `main.c`
- Any important finding goes into this document
- Any released state updates `版本记录.md`
- Any upload to GitHub should follow `GitHub上传规范.md`
